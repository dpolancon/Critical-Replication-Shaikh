# Forbidden or Strongly Discouraged Manuscript Phrases

These phrases may appear in internal editing files but should be avoided in manuscript prose unless there is a specific reason.

## Strongly discouraged

- empirical object
- object of evaluation
- capacity object
- measurement object
- interpretive move
- pressure points
- system-admissibility gates
- retained criteria
- bounded implications
- genre fit
- reader-facing
- protocol language
- naturalization
- pass scaffolding
- claim lock
- paragraph lock
- AI trace
- template leak

## Use with caution

- replication target
- candidate transformation elasticity
- self-sufficient
- portability strategy
- admissible specification space
- structural interpretation
- historical conditioning
- distributional conditioning

## Replacement principle

Replace abstract labels with the thing being discussed: coefficient, estimate, series, benchmark, specification, test, relation, model, measure.

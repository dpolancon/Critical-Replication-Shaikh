# Manuscript Lexicon

## Preferred concrete terms

| Use this | When referring to |
|---|---|
| coefficient | the long-run output-capital multiplier |
| estimate | an empirical value from ARDL/VECM |
| series | capacity utilization, output, capital, exploitation |
| measure | Shaikh’s capacity-utilization index |
| benchmark | Shaikh’s published or reconstructed baseline |
| specification | an ARDL or VECM model choice |
| relation | the output-capital long-run relation |
| test | bounds test, Johansen test, residual check |
| checks | diagnostics, stability checks, rank checks |
| empirical design | the S0/S1/S2 sequence |
| data construction | choices over corporate accounts, deflators, capital stock |

## Terms allowed but use sparingly

- transformation elasticity;
- admissibility;
- system-level;
- distributional conditioning;
- historical shock controls;
- productive-capacity path.

## Terms for internal ledgers, not manuscript prose

- object;
- gate;
- lock;
- pass;
- naturalization;
- prompt;
- system artifact;
- reader smoke test;
- template leak.

## Special note on “object”

The word “object” is not banned in all academic prose. It is banned as a default substitute for more precise empirical nouns in this manuscript.

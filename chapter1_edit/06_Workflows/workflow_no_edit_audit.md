# Workflow — No-Edit Audit

## Purpose

Assess a manuscript problem without changing the manuscript.

## Required locks

- no manuscript edits;
- no new version folder;
- no staging;
- no commit;
- no push.

## Outputs

- audit scope;
- files read;
- findings table;
- severity;
- whether a future controlled loop is recommended.

## Use cases

Reader-facing smoke test, genre-gap audit, delta audit, PDF inspection, claim-risk review.

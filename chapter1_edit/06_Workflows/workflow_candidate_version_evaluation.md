# Workflow — Candidate Version Evaluation

## Purpose

Evaluate whether a candidate rewrite should be promoted to a controlled version.

## Required checks

1. Genre fit.
2. Register cleanliness.
3. Econometric claim safety.
4. Political-economy boundary.
5. Delta against 2.7.
6. PDF readability if compiled.

## Promotion standard

A candidate should be promoted only if it is clearly better than 2.7 for the target section, not merely safer, not more generic, not more AI-like, and claim-safe under the econometric locks.

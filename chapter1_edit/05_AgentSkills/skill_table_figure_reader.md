# Skill — Table/Figure Reader

## Purpose

Check whether tables and figures carry evidence rather than acting as protocol artifacts.

## Standard inputs

- current manuscript section;
- relevant editorial contracts;
- relevant failure diagnostics;
- applicable econometric locks.

## Standard output

A concise ledger or table that records findings and recommended next action.

## Forbidden action

Do not edit the manuscript unless the active workflow explicitly authorizes paragraph-level changes.

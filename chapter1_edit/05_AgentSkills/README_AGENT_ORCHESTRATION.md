# Agent Orchestration — Chapter 1 Editing System

## Purpose

This folder defines editorial agents as bounded skills. Agents do not work as a linear pass chain. They work inside section-level loops.

## Core agents

1. Replication auditor.
2. Econometric claim guardian.
3. Genre-fit editor.
4. Register cleaner.
5. Section architect.
6. Political-economy boundary agent.
7. Table/figure reader.
8. PDF reader.
9. Handoff archivist.

## Operating rule

No agent edits the manuscript directly unless a workflow grants paragraph eligibility.

## Standard loop

1. Intake.
2. Diagnosis.
3. Paragraph lock.
4. Layered assessment.
5. Candidate rewrite.
6. Self-test.
7. Delta test.
8. PDF/readability check.
9. Promotion decision.

## Required distinction

Internal files may use system vocabulary. Manuscript prose must not leak system vocabulary unless absolutely necessary.

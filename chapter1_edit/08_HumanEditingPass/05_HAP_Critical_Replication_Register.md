# HAP Critical-Replication Register

Use Herndon, Ash, and Pollin as the standard for critical-replication discipline.

The lesson is not to imitate their sentences. The lesson is their order of operations.

## HAP sequence

1. State the original claim in the authors’ own terms.
2. Reproduce the target result before criticizing it.
3. Identify the exact sources of divergence.
4. Separate error, exclusion, weighting, data, and method.
5. Recalculate step by step.
6. Test whether the substantive claim survives reasonable alternatives.
7. State the theoretical or policy stakes only after the empirical correction is established.

## Translation to Chapter 1

1. What exactly does Shaikh’s procedure construct?
2. What coefficient draws the productive-capacity path?
3. Can the baseline path be approximately reconstructed?
4. Which differences arise from data, deflator, lag, deterministic case, or historical controls?
5. Which alternatives are admissible but not identical?
6. Which alternatives shift the object rather than stress-test the same object?
7. What does this imply for capacity utilization as a political-economy measure?

## Claim calibration

Use “error” only when the original procedure is internally inconsistent with its own declared calculation.

Use “undocumented choice” when reproduction requires reconstructing a data, lag, deflator, or dummy decision that is not fully reported.

Use “sensitive” when the result changes across reasonable alternatives.

Use “not unique” when multiple admissible specifications survive.

Use “not self-sufficient” when the bivariate relation fails the system-level test.

Use “conditioned by distribution” when the trivariate result survives with logged exploitation.

Avoid:

- “this proves Shaikh was wrong”;
- “this overturns the framework”;
- “the corrected model shows”;
- “severe omitted variable bias” unless the language is tightly justified.

Prefer:

- “the result is sensitive to…”;
- “the divergence arises from…”;
- “the alternative construction changes…”;
- “the claim is bounded rather than rejected…”;
- “the system result suggests…”;
- “the robustness check estimates a neighboring object, not the same object.”

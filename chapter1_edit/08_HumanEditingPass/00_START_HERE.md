# CH1 Human Editing Pass — Start Here

This bundle is not a new autonomous editing system. It is a human-readable compass for the next pass on Chapter 1.

The previous pass produced useful insights, but the proposed layer/pass machinery risked reproducing the very problem it was supposed to solve: a chapter that sounds engineered rather than authored. The working rule here is simpler:

> Edit the chapter against a clear argument, not against a dashboard.

The current Chapter 1 already has a serious architecture. The problem is not lack of structure. The problem is that too much structure arrives too early: abstract, introduction, theory, empirical design, and political-economy conclusions are compressed into the same argumentative space.

Use this bundle to make one human decision before editing any paragraph:

> What is the chapter actually trying to say?

The proposed answer is:

> Shaikh’s capacity-utilization index can be approximately reconstructed, but the coefficient that makes the productive-capacity path possible is not just a technical scaling parameter. Once interpreted as a transformation elasticity between capital accumulation and productive capacity, its meaning depends on specification choice, historical controls, and the distributional structure of the system.

## Recommended use

1. Read `01_Human_Outline.md` first.
2. Use `02_Argument_Compass.md` to decide whether each section belongs.
3. Rewrite only the abstract and introduction first, using `03_Abstract_Intro_Rebuild_Brief.md`.
4. Do not begin with global prose polishing.
5. Do not add new empirical claims during this editing pass.

## Protected constraint

The next pass should reduce mechanical scaffolding language. Avoid turning the chapter into a performance of methodology. Keep the argument visible, clean, and yours.
